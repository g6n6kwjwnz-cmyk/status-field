# Status Report Field

Web app (PWA) to prepare the Dashboard Timing Status report from the shop floor: photos with their component, status, comments, C. Fixture and Material.

- No data is published here: references are loaded by hand on each phone (`refs_mobile_<Owner>.json`) and reports stay on the phone until they are sent as a `.zip`.
- Install: open the GitHub Pages link in Safari (iPhone) or Chrome (Android) and use "Add to Home Screen".
